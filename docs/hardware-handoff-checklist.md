# 下周硬件对接清单

## 1. 现场需要带走的信息

- STM32 控制板 USB 接电脑后显示的设备类型
- COM 口号截图或设备管理器截图
- 串口参数：波特率、数据位、停止位、校验位
- 现有 STM32 命令表，如果已有
- 如果没有命令表，确认是否可以按本文档中的草案实现
- 底盘升降、旋转的运动单位
- 限位、回零、急停逻辑
- 摄像头型号、分辨率、帧率、是否免驱 UVC
- 压力控制设备的通信协议和电气图，后续再接入

## 2. 现场最小联调目标

第一轮现场不追求完整识别，只验证链路：

1. USB 摄像头能被 Windows 识别。
2. STM32 控制板能被 Windows 识别。
3. 上位机能列出对应 COM 口。
4. 上位机能发送一条测试命令。
5. STM32 能返回 `OK` 或状态信息。
6. 点击上升/下降/左转/右转时，底盘能执行动作。
7. 点击停止时，底盘能停止。
8. 点击回零时，底盘能回到初始位置。

## 3. 需要向老师确认的问题

### 底盘部分

- 升降旋转底盘的 STM32 程序是否已经写好。
- 如果已经写好，现有命令格式是什么。
- 如果还没写好，是否可以按我们提供的文本协议草案做。
- 底盘动作是否需要速度参数。
- 每次微调的最小步距是多少。
- 是否允许上位机连续发送微调命令。

### 摄像头部分

- 摄像头是否为普通 USB 摄像头。
- 是否需要安装驱动。
- 推荐分辨率是多少。
- 摄像头安装位置是否固定。
- 摄像头视野内是否始终只有一个仪表。

### 压力控制部分

- 压力控制协议什么时候能提供。
- 压力控制设备是 PLC、汇川控制器，还是已有上位机接口。
- 上位机是直接控制压力设备，还是只读取状态和触发流程。

## 4. 当前软件已完成的准备

- 串口扫描入口

- 自动对中流程入口
